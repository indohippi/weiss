# Weiss Project

Welcome to the Weiss project repository.

## Getting Started

This repository has been initialized and is ready for development.

### Local development

1. Install dependencies with `npm install`.
2. Launch the Vite dev server with `npm run dev`.
3. Visit the experience at [http://localhost:3000/weiss/](http://localhost:3000/weiss/) to ensure assets load from the configured base path.
